## Role of links

A **Collection Link** provides controlled access to a Collection or to a participant's part of that Collection. A link may belong to the principal applicant or be associated with a specific person.

## Principal link flow

```
POST /collections
  ↓
Collection created
  ↓
Collection access link
  ↓
Main applicant starts the Collection
```

## Person-specific link flow

```
Add Person
  ↓
Person created
  ↓
Access link generated
  ↓
Link transmitted to the person
  ↓
Person uploads documents
```

## Security properties

- **Unique** — a different link per Collection/person
- **Secure** — protected against unauthorised access
- **Revocable** — can be cancelled at any time
- **Expirable** — optional validity period
- **Traceable** — every access is recorded
- **Associated with a Collection** — always scoped to a Collection
- **Optionally associated with a Person** — can be scoped to a participant

## Links API

### Collection link

```
POST /collections/{collection_id}/link
GET  /collections/{collection_id}/link
POST /collections/{collection_id}/link/revoke
POST /collections/{collection_id}/link/resend
```

### Person-specific link

```
POST /collections/{collection_id}/persons/{person_id}/link
GET  /collections/{collection_id}/persons/{person_id}/link
POST /collections/{collection_id}/persons/{person_id}/link/revoke
POST /collections/{collection_id}/persons/{person_id}/link/resend
```
