## Definition

A **Collection** is a concrete instance of a Workflow. It represents a specific dossier being collected from one or more participants.

## Collection properties

| Property | Description |
|---|---|
| `collection_id` | Unique identifier. |
| `workflow_id` | Workflow used. |
| `title` | Human-readable title (e.g. "Apartment A"). |
| `status` | Current lifecycle status. |
| `configuration` | Options enabled at creation time. |
| `persons` | Associated participants. |
| `requirements` | Workflow requirements. |
| `result` | Structured result once analysis is complete. |
| `links` | Active access links. |
| `created_at` | Creation date. |

## Lifecycle

| Status | Meaning |
|---|---|
| `DRAFT` | The Collection has been created but is not yet active. |
| `ACTIVE` | The Collection is active and can receive documents. |
| `IN_PROGRESS` | Documents have been submitted; collection is in progress. |
| `SUBMITTED` | All required documents have been submitted. |
| `PROCESSING` | Analysis is in progress. |
| `COMPLETED` | Analysis is complete and the result is available. |
| `EXPIRED` | The Collection expired without being completed. |
| `CANCELLED` | The Collection was cancelled. |
| `REQUIRES_ACTION` | An action is required (e.g. missing or invalid document). |
| `REVIEW_REQUIRED` | A human review is required. |
| `FAILED` | A technical failure occurred. |

## Create a Collection

```bash
POST https://api.trayce.africa/v1/collections
Authorization: Bearer <your_api_key>
Content-Type: application/json

{
  "workflow_id": "tenant_application",
  "title": "Apartment A",
  "configuration": {
    "document_verification": true,
    "cross_document_consistency": true,
    "fraud_detection": true,
    "scoring": {
      "enabled": true,
      "profile_id": "apartment_premium"
    }
  }
}
```
