Instead of polling the API, receive events on your server: a document received, a document accepted, a verification completed. See the [list of events](/en/api-reference/webhooks/events).

## Format

```json
{
  "id": "evt_6a1f…",
  "type": "collect.submitted",
  "created_at": "2026-11-24T18:02:42Z",
  "data": { "id": "c41b9e02-…", "external_id": "LOC-2026-118" }
}
```

## Verify the signature

Every event carries the `Trayce-Signature: t=1795394562,v1=5d3c…` header.

1. Join `t`, a dot and the raw request body: `1795394562.{"id":"evt_6a1f…",…}`.
2. Compute the HMAC SHA-256 of this text with your webhook's `secret`.
3. Compare it with `v1`, in constant time.
4. Reject the event if `t` is more than five minutes old.

## Responding and retries

Respond `200` quickly, then process the event. Without a `2xx` response, Trayce retries several times, with increasing delays. The same event may arrive twice: use `id` to ignore duplicates.
