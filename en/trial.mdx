When you create your account, Trayce allocates **trial credits**. You call the same API as production (`https://api.trayce.africa/v1`) — create a dedicated test App if you want.

## Using credits

1. Create an App in the [Dashboard](https://app.trayce.africa).
2. Generate an API key.
3. Make your first calls (`send` or `collect`) — each operation consumes credits.
4. Track the remaining balance in the Dashboard (App tab).

## When the balance hits zero

Credit-gated operations are blocked. Upgrade to a paid plan from the Dashboard. Your Apps, API keys, and webhooks stay the same — no technical migration.

## Best practices

- Use a separate App for tests (e.g. `My product — Test`).
- Use realistic data to validate end-to-end flows.
- Monitor usage before a demo or launch.
