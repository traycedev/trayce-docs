## Endpoint

```
GET /persons/:id/links
```

## Path parameters

| Parameter | Description |
|---|---|
| `id` | Person ID (`per_...`) |

## Response `200`

```json
{
  "data": [
    {
      "id": "lnk_01HPER",
      "url": "https://collect.trayce.africa/p/xyz789",
      "type": "PERSON",
      "status": "ACTIVE",
      "expires_at": "2026-10-15T10:00:00Z"
    }
  ]
}
```
