---

## Endpoint

```
GET /collections/:id/links
```

## Path parameters

| Parameter | Description |
|---|---|
| `id` | Collection ID (`col_...`) |

## Response `200`

```json
{
  "data": [
    {
      "id": "lnk_01HXYZ",
      "url": "https://trayce.africa/collect/abc123",
      "type": "COLLECTION",
      "status": "ACTIVE",
      "expires_at": "2026-10-15T10:00:00Z"
    }
  ]
}
```
