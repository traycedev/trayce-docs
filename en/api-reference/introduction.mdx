## Base URL

```
https://api.trayce.africa/v1
```

## Authentication

```bash
Authorization: Bearer trc_live_…
```

See [Authentication](/en/authentication) for test and live modes and permissions.

## Format

- Bodies are JSON (`Content-Type: application/json`), except importing a document in Verify (`multipart/form-data`).
- Dates are UTC, in ISO 8601 format.
- Phone numbers are in international format, for example `+221771234567`.

## Lists

```json
{ "data": [...], "has_more": true, "next_cursor": "…" }
```

Parameters: `limit` (100 maximum) and `cursor` (the `next_cursor` value received).

## Avoiding duplicates

Add a unique `Idempotency-Key` header to every `POST`. If you retry with the same key, the operation is not performed twice.

## Route availability

Each route has a label:
- **Available to pilots**: you can call it with a key from your organisation.
- **Planned**: described to help you prepare your integration, it may still change.
