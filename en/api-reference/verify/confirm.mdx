<Note>Planned: this route is not open yet. It is described to help you prepare your integration and may still change.</Note>

Request confirmation of the document from its issuer or an official registry (N3). Works for a document received through Collect as well as an imported one.

```bash
POST https://api.trayce.africa/v1/verify/documents/{id}/confirm
```

Required permission: `verify:write`

## Parameters

<ParamField path="id" type="string" required>
ID of the verification.
</ParamField>

## Response

```json
{
  "id": "vrf_51c0…",
  "status": "pending",
  "checks": { "source": "pending" }
}
```

The source may take time to answer. The result arrives with the `verify.completed` event, or through [Get a verification](/en/api-reference/verify/get).
