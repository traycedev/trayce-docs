---
title: "Notify for a send document"
description: "POST /documents/send/:id/notify"
---

## Endpoint

```
POST /documents/send/:id/notify
```

Sends or resends the notification to the recipient.

## Path parameters

| Parameter | Description |
|---|---|
| `id` | Document ID (`doc_...`) |

## Request body (optional)

| Field | Type | Description |
|---|---|---|
| `channel` | string | Notification channel (`email`, `sms`) : default: `email` |

## Response `200`

```json
{
  "notified": true,
  "channel": "email",
  "sent_at": "2026-10-08T15:00:00Z"
}
```
