## Example error response

```json
{
  "error": {
    "code": "COLLECTION_ALREADY_COMPLETED",
    "message": "This Collection is already finalized.",
    "details": {
      "collection_id": "col_01HABC",
      "current_status": "COMPLETED"
    }
  }
}
```
