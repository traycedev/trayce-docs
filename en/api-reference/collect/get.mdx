<Check>Available to pilots: you can call this route with a key from your organisation.</Check>

The state of a document request.

```bash
GET https://api.trayce.africa/v1/collect/{id}
```

Required permission: `collect:read`

## Parameters

<ParamField path="id" type="string" required>
ID of the request.
</ParamField>

## Response

```json
{
  "id": "c41b9e02-6d1f-4a8e-b2c7-0f5a3d9e1b64",
  "status": "submitted",
  "recipient_phone": "+221771234567",
  "documents": [
    { "type": "national_id", "count": 1 },
    { "type": "payslip", "count": 3 },
    { "type": "proof_of_address", "count": 1 }
  ],
  "message": "Pièces pour votre dossier de location.",
  "external_id": "LOC-2026-118",
  "created_at": "2026-11-23T10:00:00Z",
  "expires_at": "2026-12-03T10:00:00Z",
  "submitted_at": "2026-11-24T18:02:41Z"
}
```

Statuses: `pending` (waiting for the person), `submitted` (documents received), `expired` (deadline passed), `cancelled` (cancelled by you).
