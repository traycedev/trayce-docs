<Note>Planned: this route is not open yet. It is described to help you prepare your integration and may still change.</Note>

Your organisation's document requests, newest first.

```bash
GET https://api.trayce.africa/v1/collect
```

Required permission: `collect:read`

## Parameters

<ParamField query="status" type="string">
`pending`, `submitted`, `expired` or `cancelled`.
</ParamField>

<ParamField query="limit" type="integer">
Number of items, 100 maximum.
</ParamField>

<ParamField query="cursor" type="string">
`next_cursor` value from the previous page.
</ParamField>
