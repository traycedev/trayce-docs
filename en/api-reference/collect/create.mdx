<Note>Planned: this route is not open yet. It is described to help you prepare your integration and may still change.</Note>

Request documents from a person. They reply from their Trayce app, or through the link if they do not have Trayce yet. Every document received is verified automatically: there is nothing more to call.

```bash
POST https://api.trayce.africa/v1/collect
```

Required permission: `collect:write`

## Parameters

<ParamField body="recipient_phone" type="string">
Phone number in international format. `recipient_phone` or `recipient_email` is required.
</ParamField>

<ParamField body="recipient_email" type="string">
Email address of the person.
</ParamField>

<ParamField body="documents" type="array" required>
Requested documents, 20 maximum. Each item: `type` (for example `national_id`, `payslip`, `proof_of_address`) and `count` (defaults to 1).
</ParamField>

<ParamField body="message" type="string">
Message shown to the person (500 characters maximum).
</ParamField>

<ParamField body="expires_in_days" type="integer">
Response deadline, from 1 to 30 days. Defaults to 7.
</ParamField>

<ParamField body="external_id" type="string">
Your own reference, for example a case number.
</ParamField>

## Example request

```bash
curl -X POST https://api.trayce.africa/v1/collect \
  -H "Authorization: Bearer trc_test_…" \
  -H "Content-Type: application/json" \
  -d '{
  "recipient_phone": "+221771234567",
  "documents": [
    { "type": "national_id" },
    { "type": "payslip", "count": 3 },
    { "type": "proof_of_address" }
  ],
  "message": "Pièces pour votre dossier de location.",
  "expires_in_days": 10,
  "external_id": "LOC-2026-118"
}'
```

## Response

```json
{
  "id": "c41b9e02-6d1f-4a8e-b2c7-0f5a3d9e1b64",
  "status": "pending",
  "url": "https://get.trayce.africa/c/K7pQ2mZx…",
  "expires_at": "2026-12-03T10:00:00Z",
  "created_at": "2026-11-23T10:00:00Z"
}
```

The person receives the request in their app, or through the `url` link, which you can also send them yourself.
