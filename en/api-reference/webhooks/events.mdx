<Note>Planned: webhooks are not open yet.</Note>

| Event | When |
|---|---|
| `send.delivered` | The document arrived in the person's app. |
| `send.accepted` | The person kept the document in their vault. |
| `send.declined` | The person declined the document. |
| `collect.submitted` | The person sent the requested documents. |
| `collect.expired` | The request expired without a reply. |
| `verify.completed` | A verification finished, or the source answered (Collect document as well as imported document). |
| `connect.accepted` | The person agreed to share their identity. |
| `connect.declined` | The person declined. |

See [Webhooks](/en/webhooks) for the format and signature verification.
