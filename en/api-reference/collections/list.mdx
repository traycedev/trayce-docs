## Endpoint

```
GET /collections
```

## Query parameters

| Parameter | Type | Description |
|---|---|---|
| `status` | string | Filter by status (`PENDING`, `IN_PROGRESS`, `COMPLETED`, `CANCELLED`) |
| `workflow_code` | string | Filter by workflow |
| `page` | integer | Page (default: 1) |
| `per_page` | integer | Results per page (default: 20) |

## Response `200`

```json
{
  "data": [
    {
      "id": "col_01HABC",
      "status": "COMPLETED",
      "workflow_code": "TENANT_APPLICATION",
      "created_at": "2026-10-08T10:00:00Z"
    }
  ],
  "pagination": { "total": 15, "page": 1, "per_page": 20, "has_more": false }
}
```
