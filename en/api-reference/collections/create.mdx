## Endpoint

```
POST /collections
```

## Request body

| Field | Type | Required | Description |
|---|---|---|---|
| `workflow_code` | string | Yes | Workflow code (e.g., `TENANT_APPLICATION`) |
| `expires_at` | string | No | Expiration date ISO 8601 |
| `metadata` | object | No | Free-form associated data |
| `webhook_url` | string | No | Override App webhook URL |

```json
{
  "workflow_code": "TENANT_APPLICATION",
  "expires_at": "2026-11-08T00:00:00Z",
  "metadata": { "property_ref": "APT-75011-B" }
}
```

## Response `201`

```json
{
  "id": "col_01HABC",
  "status": "PENDING",
  "workflow_code": "TENANT_APPLICATION",
  "expires_at": "2026-11-08T00:00:00Z",
  "metadata": { "property_ref": "APT-75011-B" },
  "created_at": "2026-10-08T10:00:00Z"
}
```
