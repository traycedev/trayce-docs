---
title: "Cancel a Collection"
description: "POST /collections/:id/cancel"
---

## Endpoint

```
POST /collections/:id/cancel
```

## Path parameters

| Parameter | Description |
|---|---|
| `id` | Collection ID (`col_...`) |

## Request body

| Field | Type | Description |
|---|---|---|
| `reason` | string | Cancellation reason (optional) |

## Response `200`

```json
{
  "id": "col_01HABC",
  "status": "CANCELLED",
  "cancelled_at": "2026-10-08T15:00:00Z"
}
```

<Warning>
  A cancelled Collection cannot be reactivated. Associated access links are automatically revoked.
</Warning>
