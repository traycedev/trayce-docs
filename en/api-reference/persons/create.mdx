---
title: "Add a Person"
description: "POST /collections/:id/persons"
---

## Endpoint

```
POST /collections/:id/persons
```

## Path parameters

| Parameter | Description |
|---|---|
| `id` | Collection ID (`col_...`) |

## Request body

| Field | Type | Required | Description |
|---|---|---|---|
| `role` | string | Yes | Role in the Collection (`PRIMARY_APPLICANT`, `CO_TENANT`, `LEGAL_REPRESENTATIVE`, `UBO`, `SUBJECT`…) |
| `first_name` | string | No | First name |
| `last_name` | string | No | Last name |
| `email` | string | No | Email (used for notifications) |
| `phone` | string | No | Phone number |
| `metadata` | object | No | Free-form data |

```json
{
  "role": "PRIMARY_APPLICANT",
  "first_name": "Jane",
  "last_name": "Smith",
  "email": "jane@example.com"
}
```

## Response `201`

```json
{
  "id": "per_01HXYZ",
  "role": "PRIMARY_APPLICANT",
  "first_name": "Jane",
  "last_name": "Smith",
  "email": "jane@example.com",
  "status": "PENDING",
  "created_at": "2026-10-08T10:00:00Z"
}
```
