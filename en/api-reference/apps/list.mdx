title: "List Apps"
description: "GET /apps"
---

## Endpoint

```
GET /apps
```

## Query parameters

| Parameter | Type | Description |
|---|---|---|
| `page` | integer | Page (default: 1) |
| `per_page` | integer | Results per page (default: 20, max: 100) |

## Response `200`

```json
{
  "data": [
    {
      "id": "app_01HABC",
      "name": "My project",
      "created_at": "2026-10-08T10:00:00Z"
    }
  ],
  "pagination": {
    "total": 3,
    "page": 1,
    "per_page": 20,
    "has_more": false
  }
}
```
