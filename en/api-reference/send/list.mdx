<Check>Available to pilots: you can call this route with a key from your organisation.</Check>

Documents sent by your organisation, newest first.

```bash
GET https://api.trayce.africa/v1/send
```

Required permission: `send:read`

## Parameters

<ParamField query="limit" type="integer">
Number of items, 100 maximum.
</ParamField>

<ParamField query="cursor" type="string">
`next_cursor` value from the previous page.
</ParamField>
