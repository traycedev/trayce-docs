## Purpose

Custom Collection provides a generic collection model for use cases that do not have a dedicated workflow in V1.

## Available configuration

- Required documents
- Optional documents
- Minimum / maximum count
- Expected document types
- Validation rules
- Expiration
- User messages
- Notification channels
- Available analyses
- Business options

## Future use cases

Future workflows mentioned in the roadmap include: Visa Application, Insurance Claim, Credit Application, Employment Verification. These workflows are not available in V1 : Custom Collection can cover these needs generically.

## Workflow code

```
CUSTOM
```

<Note>
  Custom Collection is the recommended solution for any use case not covered by the 5 other V1 workflows.
</Note>
