## Contact

For any technical or commercial question, contact the Trayce team:

- **Email**: [support@trayce.sn](mailto:support@trayce.sn)
- **Dashboard**: use the "Help" button from [app.trayce.sn](https://app.trayce.sn)

## Bug reporting

If you encounter unexpected behavior or an API error, include in your message:

- The request ID (`X-Request-ID` header in responses)
- The endpoint involved
- The payload sent (mask sensitive data)
- The response received
- The request timestamp

## Security

To report a security vulnerability: [security@trayce.sn](mailto:security@trayce.sn)
