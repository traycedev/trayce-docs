An error returns an HTTP code and a JSON body:

```json
{
  "error": "invalid_request",
  "message": "recipient_phone must be E.164 (e.g. +221771234567)."
}
```

| HTTP | `error` | Meaning |
|---|---|---|
| 400 | `invalid_request` | A parameter is missing or invalid. The message says which. |
| 401 | `invalid_api_key` | Key missing, malformed or revoked. |
| 403 | `missing_scope` | The key does not have the required permission. |
| 403 | `org_inactive` | Your organisation is not active. |
| 403 | `trial_expired` | Your trial has ended. |
| 404 | `not_found` | The object does not exist, or does not belong to your organisation. |
| 409 | `conflict` | Same `external_id` or same `Idempotency-Key` already used. |
| 429 | `rate_limited` | Too many requests. See [limits](/en/api-reference/rate-limits). |
| 5xx | `server_error` | An error on our side. Retry with the same `Idempotency-Key`. |
