<Note>Preview: the Trayce API is not open yet and may still change. Organisations in the pilot programme get early access. [Request a demo](https://trayce.africa/en).</Note>

<Steps>
  <Step title="Get a test key">
    In your Trayce Business workspace, open **API keys** and create a test key. It starts with `trc_test_`. Business workspaces are opened by the Trayce team, after a demo.
  </Step>
  <Step title="Send a test document">
    ```bash
    curl -X POST https://api.trayce.africa/v1/send \
      -H "Authorization: Bearer trc_test_…" \
      -H "Content-Type: application/json" \
      -d '{ "recipient_phone": "+221771234567", "doc_type": "payslip" }'
    ```
    With a test key, the call is validated but nothing is sent or billed.
  </Step>
  <Step title="Read the response">
    ```json
    {
      "id": "test-4f1c9a…",
      "status": "queued",
      "mode": "test"
    }
    ```
  </Step>
  <Step title="Go further">
    Discover [Collect](/en/concepts/collect) to request verified documents, or [Scan](/en/concepts/scan) to check a QR code on the spot.
  </Step>
</Steps>
