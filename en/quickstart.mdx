Goal: create an App, get a key, and make a first call : **send** or **collect**.

## Steps

<Steps>
  <Step title="Create an account">
    Go to [app.trayce.africa](https://app.trayce.africa) and create your company account.
  </Step>
  <Step title="Create an App">
    In the Dashboard, create an App. It owns its keys, permissions, and webhooks.
  </Step>
  <Step title="Generate an API key">
    In the App settings, generate a key. **Copy it immediately** : it is shown only once.
  </Step>
  <Step title="Check permissions">
    Keep at least `documents:write` and/or `collections:write` for your use case.
  </Step>
  <Step title="First call">
    Use trial credits for a `send` or `collect` (examples below).
  </Step>
  <Step title="Webhooks (optional)">
    Add your endpoint URL in the App settings to receive events.
  </Step>
</Steps>

## First send

```bash
curl -X POST https://api.trayce.africa/v1/documents \
  -H "Authorization: Bearer <your_api_key>" \
  -H "Content-Type: application/json" \
  -d '{
    "recipient_phone_number": "+221xxxxxxxxx",
    "document_type": "PAYSLIP",
    "title": "Payslip : September"
  }'
```

## First collect

```bash
curl -X POST https://api.trayce.africa/v1/collections \
  -H "Authorization: Bearer <your_api_key>" \
  -H "Content-Type: application/json" \
  -d '{
    "workflow_id": "tenant_application",
    "title": "Apartment A",
    "configuration": {
      "document_verification": true,
      "cross_document_consistency": true,
      "fraud_detection": true,
      "scoring": {
        "enabled": true,
        "profile_id": "apartment_premium"
      }
    }
  }'
```
