## Overview

Webhooks allow your backend to receive automatic notifications when an event occurs in Trayce, without continuously polling the API.

## Steps

<Steps>
  <Step title="Create an endpoint on your server">
    Your endpoint must:
    - Accept `POST` requests
    - Respond with a `200` status within 5 seconds
    - Process the payload in the background if needed

    ```javascript
    app.post('/webhooks/trayce', (req, res) => {
      const event = req.body;
      res.status(200).send('OK');
      // process the event in the background
      processEvent(event);
    });
    ```
  </Step>

  <Step title="Register the endpoint in the Dashboard">
    In the Trayce Dashboard (`app.trayce.sn`), go to **Settings > Webhooks** and add your URL.
  </Step>

  <Step title="Select events">
    Choose which events to receive:

    | Event | Trigger |
    |---|---|
    | `collection.completed` | Collection finalized with results |
    | `collection.review_required` | Human review required |
    | `collection.cancelled` | Collection cancelled |
    | `document.received` | New document submitted |
    | `person.completed` | All documents for a person received |
  </Step>

  <Step title="Verify the signature">
    <Note>
      Signature verification via shared secret is being finalized. Technical details will be available at production launch.
    </Note>
  </Step>

  <Step title="Test with trial credits">
    Use your test environment (trial credits) to simulate events before going live.
  </Step>
</Steps>
