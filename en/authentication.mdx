## Apps

An **App** is your integration identity: API keys, permissions, webhooks.

| | |
|---|---|
| App ID | App identifier |
| API keys | Authenticate your calls |
| Permissions | What the App can do |
| Webhooks | Event delivery URL |

You can have several Apps (e.g. one per product or internal environment).

## API keys

Generate them from the Dashboard → App settings.

<Warning>
  The full key is shown **only at creation**. Store it in a secrets manager. If lost: create a new key and revoke the old one.
</Warning>

```bash
curl https://api.trayce.africa/v1/collections \
  -H "Authorization: Bearer <your_api_key>" \
  -H "Content-Type: application/json"
```

### Rotation

- Revoke a compromised key immediately.
- Use multiple keys per App for zero-downtime rotation.
- A revoked key is invalidated at once.

## Permissions

| Permission | Use |
|---|---|
| `documents:write` | Send documents |
| `documents:read` | Read documents and statuses |
| `collections:write` | Create / update Collections |
| `collections:read` | Read Collections and results |
| `applications:read` | Read App resources |
| `webhooks:manage` | Manage webhooks |

Grant only what the integration needs.

## Apps API

```
POST   /apps
GET    /apps
GET    /apps/{app_id}
PATCH  /apps/{app_id}
DELETE /apps/{app_id}
```
