## Versioning

The Trayce API uses URL path versioning: `/v1/`, `/v2/`, etc. Non-breaking changes are introduced in the current version. Breaking changes result in a new version.

## v1 — Current version

**October 2026**

Initial release of the Trayce Business API.

### Primitives

- **send**: document transmission with secure links and notifications
- **collect**: structured document collection via Workflows

### Available workflows

- `IDENTITY_VERIFICATION`
- `KYC`
- `KYB`
- `TENANT_APPLICATION`
- `CIVIL_STATUS_DOCUMENT_ANALYSIS`
- `CUSTOM`

### Resources

- Apps, Collections, Persons, Links, Documents, Results, Webhooks

### Analysis

- AI Engine: classification, extraction, verification, consistency
- Business Rules
- Scoring
