Trayce's document exchange API gives you a secure, consent-driven channel for moving sensitive documents between your platform and individuals' Trayce Vaults. Whether you need a customer to share their proof of address or you need to deliver a signed contract to a recipient, every transfer is end-to-end encrypted and requires explicit approval from the vault holder. No document ever passes through your servers in plaintext.

---

## Requesting a Document

<Steps>

  <Step title="Create a Document Request">
    Call `POST /documents/request` with the recipient's contact details, the type of document you need, a human-readable reason, and an optional expiry window.

    ```bash Request
    curl -X POST https://api.trayce.io/v1/documents/request \
      -H "Authorization: Bearer <api_key>" \
      -H "Content-Type: application/json" \
      -d '{
        "recipient": {
          "email": "jane.doe@example.com"
        },
        "document_type": "proof_of_address",
        "reason": "Required to verify your residential address as part of our account opening process.",
        "expires_in": 259200
      }'
    ```

    ```json Response
    {
      "id": "doc_req_07VWBZ3CLNP2QXRM5AKTE8SHY",
      "status": "pending",
      "recipient": {
        "email": "jane.doe@example.com"
      },
      "document_type": "proof_of_address",
      "reason": "Required to verify your residential address as part of our account opening process.",
      "expires_at": "2024-07-18T14:30:00Z",
      "created_at": "2024-07-15T14:30:00Z"
    }
    ```

    Store the `id` — you'll use it to poll for the document status or match incoming webhook events.
  </Step>

  <Step title="Vault Holder Reviews the Request">
    The recipient receives a push notification in their Trayce Vault app (or an email/SMS link if they have not installed the app). The request screen displays:

    - Your organization's verified name and logo.
    - The document type being requested.
    - The reason you provided.
    - The expiry deadline.

    The vault holder can **approve** the request (sharing the selected document from their Vault or uploading a new one) or **reject** it. Trayce records the holder's explicit consent before any document is transmitted.
  </Step>

  <Step title="Receive the Outcome">
    You will be notified of the vault holder's decision in real time via webhook, or you can poll the document endpoint.

    **Option A — Webhook events:**

    | Event | Meaning |
    |---|---|
    | `document.approved` | The vault holder approved the request and the document is available. |
    | `document.rejected` | The vault holder declined to share the document. |
    | `document.expired` | The request was not acted upon before `expires_at`. |

    **Option B — Poll the request:**

    ```bash
    curl https://api.trayce.io/v1/documents/doc_req_07VWBZ3CLNP2QXRM5AKTE8SHY \
      -H "Authorization: Bearer <api_key>"
    ```

    When `status` is `"approved"`, the response includes a `download_url` — a short-lived authenticated URL you can use to retrieve the document file.
  </Step>

</Steps>

## Sending a Document

<Steps>

  <Step title="Send a Document to a Vault Holder">
    Call `POST /documents/send` as a `multipart/form-data` request. Include the document file, its type, the recipient's contact details, and an optional message.

    ```bash Request
    curl -X POST https://api.trayce.io/v1/documents/send \
      -H "Authorization: Bearer <api_key>" \
      -F "file=@/path/to/signed_contract.pdf" \
      -F "document_type=company_registration" \
      -F "recipient[email]=jean.dupont@example.com" \
      -F "message=Please find your countersigned agreement attached. Store it securely in your Vault."
    ```

    ```json Response
    {
      "id": "doc_snd_13YTXK9FPQH7WUNV0BCSE2DRG",
      "status": "delivered",
      "recipient": {
        "email": "jean.dupont@example.com"
      },
      "document_type": "company_registration",
      "message": "Please find your countersigned agreement attached. Store it securely in your Vault.",
      "delivered_at": "2024-07-15T15:02:11Z",
      "created_at": "2024-07-15T15:02:09Z"
    }
    ```
  </Step>

  <Step title="Recipient is Notified">
    The recipient receives a push notification alerting them that a new document has arrived in their Vault. They can open it, view its details, and choose to save it to a specific folder in their Vault. The document is encrypted at rest and only accessible to that vault holder.

    Your organization's verified name is displayed prominently so the recipient knows who sent the document.
  </Step>

  <Step title="Confirm Delivery">
    Trayce confirms delivery as soon as the document is securely written to the recipient's Vault — this typically happens within seconds.

    **Option A — Webhook event:**

    Listen for the `document.delivered` event on your registered webhook endpoint. The payload includes the `document_id`, `recipient`, and `delivered_at` timestamp.

    **Option B — Poll the send record:**

    ```bash
    curl https://api.trayce.io/v1/documents/doc_snd_13YTXK9FPQH7WUNV0BCSE2DRG \
      -H "Authorization: Bearer <api_key>"
    ```

    Check `status` — it will be `"delivered"` once the document has reached the recipient's Vault, or `"failed"` if delivery could not be completed (e.g. the recipient's Vault is deactivated).
  </Step>

</Steps>

## Supported Document Types

Use these values in the `document_type` field for both document requests and document sends.

| `document_type` | Description |
|---|---|
| `national_id` | Government-issued national identity card. |
| `passport` | International travel passport. |
| `driver_license` | Driving licence / driver's license. |
| `proof_of_address` | Utility bill, bank statement, or official letter confirming residential address (typically less than 3 months old). |
| `diploma` | Academic degree certificate or diploma. |
| `birth_certificate` | Official birth certificate issued by a civil registry. |
| `marriage_certificate` | Official marriage certificate issued by a civil registry. |
| `company_registration` | Company registration certificate, KBIS extract, or equivalent official business registration document. |

If the document type you need is not listed, use `"other"` and provide a description in the `reason` field (for requests) or `message` field (for sends). Trayce will display the raw description to the vault holder.

---

<Warning>
  Document requests expire after **72 hours by default** (`expires_in: 259200` seconds). Once a request expires, it cannot be reactivated — you must create a new request. If your workflow requires a longer window, you can set `expires_in` to up to **604800 seconds (7 days)**. Requests that expire without a response trigger a `document.expired` webhook event so you can take appropriate action (e.g. send a follow-up or flag the case for manual review).
</Warning>
