## Endpoint

```
GET /apps
```

## Paramètres de requête

| Paramètre | Type | Description |
|---|---|---|
| `page` | integer | Page (défaut : 1) |
| `per_page` | integer | Résultats par page (défaut : 20, max : 100) |

## Réponse `200`

```json
{
  "data": [
    {
      "id": "app_01HABC",
      "name": "Mon projet",
      "created_at": "2026-10-08T10:00:00Z"
    }
  ],
  "pagination": {
    "total": 3,
    "page": 1,
    "per_page": 20,
    "has_more": false
  }
}
```
