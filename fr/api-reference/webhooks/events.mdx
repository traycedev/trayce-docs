<Note>Prévue : les webhooks ne sont pas encore ouverts.</Note>

| Événement | Quand |
|---|---|
| `send.delivered` | Le document est arrivé dans l'application de la personne. |
| `send.accepted` | La personne a rangé le document dans son coffre. |
| `send.declined` | La personne a refusé le document. |
| `collect.submitted` | La personne a envoyé les pièces demandées. |
| `collect.expired` | La demande a expiré sans réponse. |
| `verify.completed` | Une vérification est terminée, ou la source a répondu (pièce de Collect comme document importé). |
| `connect.accepted` | La personne a accepté de partager son identité. |
| `connect.declined` | La personne a refusé. |

Voir [Webhooks](/fr/webhooks) pour le format et la vérification de la signature.
