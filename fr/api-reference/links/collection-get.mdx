---
title: "Récupérer le lien Collection"
description: "GET /collections/:id/links"
---

## Endpoint

```
GET /collections/:id/links
```

## Paramètres de chemin

| Paramètre | Description |
|---|---|
| `id` | ID de la Collection (`col_...`) |

## Réponse `200`

```json
{
  "data": [
    {
      "id": "lnk_01HXYZ",
      "url": "https://trayce.africa/collect/abc123",
      "type": "COLLECTION",
      "status": "ACTIVE",
      "expires_at": "2026-10-15T10:00:00Z"
    }
  ]
}
```
