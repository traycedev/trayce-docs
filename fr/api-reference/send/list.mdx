<Check>Disponible pour les pilotes : vous pouvez appeler cette route avec une clé de votre organisation.</Check>

Les documents émis par votre organisation, du plus récent au plus ancien.

```bash
GET https://api.trayce.africa/v1/send
```

Permission requise : `send:read`

## Paramètres

<ParamField query="limit" type="integer">
Nombre d'éléments, 100 au maximum.
</ParamField>

<ParamField query="cursor" type="string">
Valeur `next_cursor` de la page précédente.
</ParamField>
