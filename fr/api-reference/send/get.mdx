<Check>Disponible pour les pilotes : vous pouvez appeler cette route avec une clé de votre organisation.</Check>

L'état d'un document émis et les dates de chaque étape.

```bash
GET https://api.trayce.africa/v1/send/{id}
```

Permission requise : `send:read`

## Paramètres

<ParamField path="id" type="string" required>
Identifiant de l'envoi.
</ParamField>

## Réponse

```json
{
  "id": "8d0c6f1e-2b7a-4c3e-9a51-5f2e0b7d4c18",
  "status": "viewed",
  "mode": "live",
  "doc_type": "payslip",
  "recipient_phone": "+221771234567",
  "external_id": "PAIE-2026-11-0042",
  "expires_at": "2026-12-07T10:00:00Z",
  "created_at": "2026-11-23T10:00:00Z",
  "delivered_at": "2026-11-23T10:00:04Z",
  "viewed_at": "2026-11-23T12:31:10Z",
  "accepted_at": null,
  "declined_at": null,
  "revoked_at": null
}
```

Statuts : `queued` (créé), `delivered` (arrivé dans l'application), `viewed` (ouvert), `accepted` (rangé dans le coffre), `declined` (refusé par la personne), `revoked` (retiré par vous), `expired` (non récupéré à temps).
