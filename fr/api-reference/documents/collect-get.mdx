## Endpoint

```
GET /collections/:collection_id/documents/:id
```

## Paramètres de chemin

| Paramètre | Description |
|---|---|
| `collection_id` | ID de la Collection (`col_...`) |
| `id` | ID du document collect (`cdoc_...`) |
