---
title: "Notifier pour un document send"
description: "POST /documents/send/:id/notify"
---

## Endpoint

```
POST /documents/send/:id/notify
```

Envoie ou renvoie la notification au destinataire.

## Paramètres de chemin

| Paramètre | Description |
|---|---|
| `id` | ID du document (`doc_...`) |

## Corps de la requête (optionnel)

| Champ | Type | Description |
|---|---|---|
| `channel` | string | Canal de notification (`email`, `sms`) : défaut : `email` |

## Réponse `200`

```json
{
  "notified": true,
  "channel": "email",
  "sent_at": "2026-10-08T15:00:00Z"
}
```
