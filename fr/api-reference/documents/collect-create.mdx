## Endpoint

```
POST /collections/:id/documents
```

Soumet un document à une Collection (upload direct par l'intégrateur, sans passer par le lien d'accès).

## Paramètres de chemin

| Paramètre | Description |
|---|---|
| `id` | ID de la Collection (`col_...`) |

## Corps de la requête (multipart/form-data)

| Champ | Type | Requis | Description |
|---|---|---|---|
| `file` | file | Oui | Fichier document |
| `document_type` | string | Oui | Type de document |
| `person_id` | string | Non | ID de la Personne associée |

## Réponse `201`

```json
{
  "id": "cdoc_01HABC",
  "collection_id": "col_01HXYZ",
  "document_type": "PAY_SLIP",
  "status": "PROCESSING",
  "created_at": "2026-10-08T10:00:00Z"
}
```
