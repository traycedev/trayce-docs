---
title: "Lister les documents send"
description: "GET /documents/send"
---

## Endpoint

```
GET /documents/send
```

## Paramètres de requête

| Paramètre | Type | Description |
|---|---|---|
| `status` | string | Filtrer par statut (`PENDING`, `VIEWED`, `EXPIRED`, `REVOKED`) |
| `page` | integer | Page (défaut : 1) |
| `per_page` | integer | Résultats par page (défaut : 20) |

## Réponse `200`

```json
{
  "data": [
    {
      "id": "doc_01HXYZ",
      "status": "VIEWED",
      "document_type": "CONTRACT",
      "recipient_email": "destinataire@example.com",
      "viewed_at": "2026-10-09T08:00:00Z",
      "created_at": "2026-10-08T10:00:00Z"
    }
  ],
  "pagination": { "total": 5, "page": 1, "per_page": 20, "has_more": false }
}
```
