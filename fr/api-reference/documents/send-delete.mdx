---
title: "Supprimer un document send"
description: "DELETE /documents/send/:id"
---

## Endpoint

```
DELETE /documents/send/:id
```

## Paramètres de chemin

| Paramètre | Description |
|---|---|
| `id` | ID du document (`doc_...`) |

## Réponse `204`

Corps vide. Le fichier et le lien d'accès associés sont supprimés.
