<Check>Disponible pour les pilotes : vous pouvez appeler cette route avec une clé de votre organisation.</Check>

L'état d'une demande de pièces.

```bash
GET https://api.trayce.africa/v1/collect/{id}
```

Permission requise : `collect:read`

## Paramètres

<ParamField path="id" type="string" required>
Identifiant de la demande.
</ParamField>
