<Note>Prévue : cette route n'est pas encore ouverte. Elle est décrite pour vous aider à préparer votre intégration et peut encore évoluer.</Note>

Les demandes de pièces de votre organisation, de la plus récente à la plus ancienne.

```bash
GET https://api.trayce.africa/v1/collect
```

Permission requise : `collect:read`

## Paramètres

<ParamField query="status" type="string">
`pending`, `submitted`, `expired` ou `cancelled`.
</ParamField>

<ParamField query="limit" type="integer">
Nombre d'éléments, 100 au maximum.
</ParamField>

<ParamField query="cursor" type="string">
Valeur `next_cursor` de la page précédente.
</ParamField>
