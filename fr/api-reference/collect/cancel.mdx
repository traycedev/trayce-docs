<Note>Prévue : cette route n'est pas encore ouverte. Elle est décrite pour vous aider à préparer votre intégration et peut encore évoluer.</Note>

Annulez une demande en attente. La personne ne peut plus y répondre.

```bash
POST https://api.trayce.africa/v1/collect/{id}/cancel
```

Permission requise : `collect:write`

## Paramètres

<ParamField path="id" type="string" required>
Identifiant de la demande.
</ParamField>

## Réponse

```json
{
  "id": "c41b9e02-6d1f-4a8e-b2c7-0f5a3d9e1b64",
  "status": "cancelled"
}
```
