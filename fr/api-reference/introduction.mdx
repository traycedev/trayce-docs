<Note>Aperçu : l'API Trayce n'est pas encore ouverte et peut encore évoluer. Les organisations du programme pilote y ont accès en avant-première. [Demander une démo](https://trayce.africa).</Note>

## Adresse

```
https://api.trayce.africa/v1
```

## Authentification

```bash
Authorization: Bearer trc_live_…
```

Voir [Authentification](/fr/authentication) pour les modes test et live et les permissions.

## Format

- Les corps sont en JSON (`Content-Type: application/json`), sauf l'import d'un document dans Verify (`multipart/form-data`).
- Les dates sont en UTC, au format ISO 8601.
- Les numéros de téléphone sont au format international, par exemple `+221771234567`.

## Listes

```json
{ "data": [...], "has_more": true, "next_cursor": "…" }
```

Paramètres : `limit` (100 au maximum) et `cursor` (la valeur `next_cursor` reçue).

## Éviter les doublons

Ajoutez un en-tête `Idempotency-Key` unique à chaque `POST`. En cas de nouvel essai avec la même clé, l'opération n'est pas faite deux fois.

## Disponibilité des routes

Chaque route porte une étiquette :
- **Disponible pour les pilotes** : vous pouvez l'appeler avec une clé de votre organisation.
- **Prévue** : décrite pour préparer votre intégration, elle peut encore évoluer.
