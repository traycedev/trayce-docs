## Endpoint

```
POST /collections
```

## Corps de la requête

| Champ | Type | Requis | Description |
|---|---|---|---|
| `workflow_code` | string | Oui | Code du workflow (ex. : `TENANT_APPLICATION`) |
| `expires_at` | string | Non | Date d'expiration ISO 8601 |
| `metadata` | object | Non | Données libres associées |
| `webhook_url` | string | Non | Override du webhook de l'App |

```json
{
  "workflow_code": "TENANT_APPLICATION",
  "expires_at": "2026-11-08T00:00:00Z",
  "metadata": { "property_ref": "APT-75011-B" }
}
```

## Réponse `201`

```json
{
  "id": "col_01HABC",
  "status": "PENDING",
  "workflow_code": "TENANT_APPLICATION",
  "expires_at": "2026-11-08T00:00:00Z",
  "metadata": { "property_ref": "APT-75011-B" },
  "created_at": "2026-10-08T10:00:00Z"
}
```
