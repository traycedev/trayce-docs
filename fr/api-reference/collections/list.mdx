## Endpoint

```
GET /collections
```

## Paramètres de requête

| Paramètre | Type | Description |
|---|---|---|
| `status` | string | Filtrer par statut (`PENDING`, `IN_PROGRESS`, `COMPLETED`, `CANCELLED`) |
| `workflow_code` | string | Filtrer par workflow |
| `page` | integer | Page (défaut : 1) |
| `per_page` | integer | Résultats par page (défaut : 20) |

## Réponse `200`

```json
{
  "data": [
    {
      "id": "col_01HABC",
      "status": "COMPLETED",
      "workflow_code": "TENANT_APPLICATION",
      "created_at": "2026-10-08T10:00:00Z"
    }
  ],
  "pagination": { "total": 15, "page": 1, "per_page": 20, "has_more": false }
}
```
