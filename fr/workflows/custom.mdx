## Objectif

La Collection personnalisée fournit un modèle de collecte générique pour les cas d'usage qui ne disposent pas de workflow dédié en V1.

## Configuration disponible

- Documents requis
- Documents optionnels
- Nombre minimum / maximum
- Types de documents attendus
- Règles de validation
- Expiration
- Messages utilisateur
- Canaux de notification
- Analyses disponibles
- Options métier

## Cas d'usage futurs

Les workflows futurs mentionnés dans la feuille de route incluent : Demande de visa, Sinistre assurance, Demande de crédit, Vérification d'emploi. Ces workflows ne sont pas disponibles en V1 — la Collection personnalisée peut couvrir ces besoins de manière générique.
