---
title: "Démarrage rapide"
icon: "rocket"
description: "Votre premier appel en quelques minutes, avec une clé de test."
---

<Note>Aperçu : l'API Trayce n'est pas encore ouverte et peut encore évoluer. Les organisations du programme pilote y ont accès en avant-première. [Demander une démo](https://trayce.africa).</Note>

<Steps>
  <Step title="Obtenir une clé de test">
    Dans votre espace Trayce Business, ouvrez **Clés API** et créez une clé de test. Elle commence par `trc_test_`. Les espaces Business sont ouverts par l'équipe Trayce, après une démo.
  </Step>
  <Step title="Émettre un document de test">
    ```bash
    curl -X POST https://api.trayce.africa/v1/send \
      -H "Authorization: Bearer trc_test_…" \
      -H "Content-Type: application/json" \
      -d '{ "recipient_phone": "+221771234567", "doc_type": "payslip" }'
    ```
    Avec une clé de test, l'appel est validé mais rien n'est envoyé ni facturé.
  </Step>
  <Step title="Lire la réponse">
    ```json
    {
      "id": "test-4f1c9a…",
      "status": "queued",
      "mode": "test"
    }
    ```
  </Step>
  <Step title="Aller plus loin">
    Découvrez [Collect](/fr/concepts/collect) pour demander des pièces vérifiées, ou [Scan](/fr/concepts/scan) pour contrôler un Pass sur place.
  </Step>
</Steps>
