## Objectif

Créer une App, obtenir des identifiants et réaliser un premier appel API — soit un **send** pour transmettre un document, soit un **collect** pour initier une Collection.

## Flux d'intégration recommandé

<Steps>
  <Step title="Créer un compte Trayce Business">
    Rendez-vous sur [app.trayce.sn](https://app.trayce.sn) et créez votre compte entreprise.
  </Step>
  <Step title="Créer une App">
    Depuis le Dashboard, créez une App pour votre intégration. Chaque App possède ses propres identifiants, permissions et webhooks.
  </Step>
  <Step title="Générer une clé API">
    Dans les paramètres de l'App, générez une clé API. **Conservez-la immédiatement** — elle n'est affichée qu'une seule fois.
  </Step>
  <Step title="Vérifier les permissions">
    Passez en revue les permissions accordées à l'App (`documents:write`, `collections:write`, etc.) et ajustez selon vos besoins.
  </Step>
  <Step title="Utiliser les crédits d'essai">
    La période d'essai inclut des crédits gratuits pour tester votre intégration. Consultez la page [Essai & Crédits](/fr/trial) pour plus de détails.
  </Step>
  <Step title="Réaliser un premier appel">
    Envoyez un document ou créez une Collection (voir ci-dessous).
  </Step>
  <Step title="Configurer les webhooks (optionnel)">
    Si votre intégration nécessite des événements asynchrones, configurez un endpoint webhook dans les paramètres de l'App.
  </Step>
  <Step title="Surveiller l'usage">
    Consultez l'utilisation et les crédits restants depuis le Dashboard.
  </Step>
</Steps>

## Premier send

`send` est le chemin le plus court pour une intégration qui doit uniquement transmettre un document à un utilisateur.

```bash
POST https://api.trayce.africa/v1/documents
Authorization: Bearer <votre_clé_api>
Content-Type: application/json

{
  "recipient_phone_number": "+221xxxxxxxxx",
  "document_type": "PAYSLIP",
  "title": "Bulletin de salaire — Septembre"
}
```

<Note>
  Le schéma exact de la requête sera finalisé avant la publication de la documentation de production. L'exemple ci-dessus est illustratif.
</Note>

## Premier collect

```bash
POST https://api.trayce.africa/v1/collections
Authorization: Bearer <votre_clé_api>
Content-Type: application/json

{
  "workflow_id": "tenant_application",
  "title": "Appartement A",
  "configuration": {
    "document_verification": true,
    "cross_document_consistency": true,
    "fraud_detection": true,
    "scoring": {
      "enabled": true,
      "profile_id": "apartment_premium"
    }
  }
}
```
