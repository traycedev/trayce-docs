Objectif : créer une App, récupérer une clé, et faire un premier appel — **send** ou **collect**.

## Étapes

<Steps>
  <Step title="Créer un compte">
    Allez sur [app.trayce.africa](https://app.trayce.africa) et créez votre compte entreprise.
  </Step>
  <Step title="Créer une App">
    Dans le Dashboard, créez une App. Elle porte ses clés, permissions et webhooks.
  </Step>
  <Step title="Générer une clé API">
    Dans les paramètres de l'App, générez une clé. **Copiez-la tout de suite** — elle n'est affichée qu'une fois.
  </Step>
  <Step title="Vérifier les permissions">
    Gardez au minimum `documents:write` et/ou `collections:write` selon votre cas.
  </Step>
  <Step title="Premier appel">
    Utilisez les crédits d'essai pour un `send` ou un `collect` (exemples ci-dessous).
  </Step>
  <Step title="Webhooks (optionnel)">
    Ajoutez l'URL de votre endpoint dans les paramètres de l'App pour recevoir les événements.
  </Step>
</Steps>

## Premier send

```bash
curl -X POST https://api.trayce.africa/v1/documents \
  -H "Authorization: Bearer <votre_clé_api>" \
  -H "Content-Type: application/json" \
  -d '{
    "recipient_phone_number": "+221xxxxxxxxx",
    "document_type": "PAYSLIP",
    "title": "Bulletin de salaire — Septembre"
  }'
```

## Premier collect

```bash
curl -X POST https://api.trayce.africa/v1/collections \
  -H "Authorization: Bearer <votre_clé_api>" \
  -H "Content-Type: application/json" \
  -d '{
    "workflow_id": "tenant_application",
    "title": "Appartement A",
    "configuration": {
      "document_verification": true,
      "cross_document_consistency": true,
      "fraud_detection": true,
      "scoring": {
        "enabled": true,
        "profile_id": "apartment_premium"
      }
    }
  }'
```
