## Vue d'ensemble

Les webhooks permettent à votre backend de recevoir des notifications automatiques lorsqu'un événement survient dans Trayce, sans avoir à interroger l'API en permanence.

## Étapes

<Steps>
  <Step title="Créer un endpoint sur votre serveur">
    Votre endpoint doit :
    - Accepter les requêtes `POST`
    - Répondre avec un statut `200` en moins de 5 secondes
    - Traiter le payload en arrière-plan si nécessaire

    ```javascript
    app.post('/webhooks/trayce', (req, res) => {
      const event = req.body;
      res.status(200).send('OK');
      // traiter l'événement en arrière-plan
      processEvent(event);
    });
    ```
  </Step>

  <Step title="Enregistrer l'endpoint dans le Dashboard">
    Dans le Dashboard Trayce (`app.trayce.africa`), accédez à **Paramètres > Webhooks** et ajoutez votre URL.
  </Step>

  <Step title="Sélectionner les événements">
    Choisissez les événements à recevoir :

    | Événement | Déclencheur |
    |---|---|
    | `collection.completed` | Collection finalisée avec résultats |
    | `collection.review_required` | Revue humaine nécessaire |
    | `collection.cancelled` | Collection annulée |
    | `document.received` | Nouveau document soumis |
    | `person.completed` | Tous les docs d'une personne reçus |
  </Step>

  <Step title="Vérifier la signature">
    Utilisez le secret webhook de l'App et l'en-tête `X-Trayce-Signature` (HMAC-SHA256). Détails : [Webhooks](/fr/webhooks#sécurité).
  </Step>

  <Step title="Tester">
    Déclenchez un `send` ou un `collect` avec vos crédits d'essai et vérifiez la réception sur votre endpoint.
  </Step>
</Steps>
