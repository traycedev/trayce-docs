## Vue d'ensemble

Trayce fournit des crédits d'essai gratuits à la création de votre compte App. Ces crédits vous permettent de tester votre intégration en conditions réelles, sans facturation.

## Comment ça marche

- Vos crédits d'essai sont disponibles immédiatement après création de l'App dans le Dashboard.
- Chaque opération (Collection créée, document analysé) consomme des crédits selon la grille tarifaire.
- Une fois les crédits épuisés, passez au plan payant depuis le Dashboard.

## Bonne pratique

<Steps>
  <Step title="Créer une App de test dédiée">
    Créez une App distincte dans le Dashboard avec un label reconnaissable (ex. : "Mon projet — Test").
  </Step>

  <Step title="Utiliser de vraies données de test">
    Les crédits d'essai fonctionnent sur les mêmes endpoints que la production. Utilisez des données réalistes pour valider vos flux.
  </Step>

  <Step title="Surveiller la consommation">
    Consultez le Dashboard (`app.trayce.sn`) pour suivre l'utilisation de vos crédits.
  </Step>

  <Step title="Passer en production">
    Quand votre intégration est validée, activez le plan payant. Vos App IDs et clés API restent identiques.
  </Step>
</Steps>

<Note>
  Il n'existe pas d'environnement "Sandbox" séparé. Les crédits d'essai s'utilisent sur la même API que la production — `https://api.trayce.africa/v1`.
</Note>
