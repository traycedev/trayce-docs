Avec Collect, vous demandez des pièces à une personne : pièce d'identité, bulletins de salaire, justificatif de domicile.

## Comment ça marche

1. Vous créez une demande : les pièces voulues, un message, un délai.
2. La personne répond depuis son application Trayce, ou par un lien si elle n'a pas encore Trayce.
3. Les pièces arrivent dans votre espace, **chacune avec sa vérification**.

## Verify est inclus

Chaque pièce reçue est vérifiée automatiquement, sans appel de plus :
- elle est analysée (**N1**) ;
- si elle a été émise dans Trayce, sa signature est contrôlée (**N2**) ;
- vous pouvez demander la confirmation à la source (**N3**) pour les pièces qui comptent.

Voir les [niveaux de vérification](/fr/concepts/verify).

## Ce qui est garanti

- La personne choisit ce qu'elle envoie et voit à qui.
- Les pièces sont chiffrées pour votre organisation : Trayce ne peut pas les lire.

## Exemple : un dossier de location

Une agence immobilière demande à Aïssatou Ba, candidate à une location, les pièces de son dossier.

1. L'agence crée la demande avec [Demander des pièces](/fr/api-reference/collect/create) :

```json
{
  "recipient_phone": "+221771234567",
  "documents": [
    { "type": "national_id" },
    { "type": "payslip", "count": 3 },
    { "type": "proof_of_address" }
  ],
  "message": "Pièces pour votre dossier de location.",
  "external_id": "LOC-2026-118"
}
```

2. Aïssatou répond depuis son application en quelques gestes : ses pièces y sont déjà.
3. L'agence reçoit l'événement `collect.submitted`, puis lit les [pièces reçues](/fr/api-reference/collect/documents) : les bulletins émis par l'employeur dans Trayce arrivent au niveau **N2**, le justificatif de domicile au niveau **N1**.
4. Pour les bulletins, l'agence demande la [confirmation à la source](/fr/api-reference/verify/confirm) : l'employeur confirme, et ils passent au niveau **N3**.

## Dans l'API

[Suivre une demande](/fr/api-reference/collect/get) est disponible pour les pilotes. La création d'une demande et la lecture des pièces sont prévues : les pilotes peuvent déjà faire ce parcours depuis leur espace Trayce Business.
