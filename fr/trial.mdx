## Pourquoi il n'y a pas d'environnement Sandbox

Le modèle produit de Trayce Business repose sur une **période d'essai avec des crédits gratuits** plutôt que sur des environnements Sandbox et Production séparés. L'essai permet d'intégrer et de tester dans les mêmes conditions que la production, sans infrastructure supplémentaire.

## Période d'essai

La période d'essai permet à une entreprise d'évaluer Trayce et de valider son intégration avant de passer à un usage payant. L'accès à l'essai est basé sur des crédits gratuits.

## Crédits gratuits

Les crédits représentent l'enveloppe d'usage offerte pendant l'essai.

<Note>
  Le nombre exact de crédits, les règles d'expiration et les taux de consommation sont des paramètres commerciaux non encore définis. Cette page sera mise à jour avant la publication.
</Note>

| Sujet | Description |
|---|---|
| Éligibilité | Toute nouvelle entreprise créant un compte Trayce Business. |
| Allocation initiale | À définir. |
| Expiration | À définir. |
| Consommation | Les opérations consommatrices de crédits seront listées ici. |
| Solde | Visible depuis le Dashboard, onglet App. |
| Épuisement | Lorsque le solde atteint zéro, les opérations soumises à crédits sont bloquées jusqu'à la mise à niveau. |
| Mise à niveau | Passage à l'offre payante depuis le Dashboard. |

## Surveiller l'usage pendant l'essai

Le Dashboard affiche en temps réel :
- Le solde de crédits restants
- Le détail des opérations consommées
- La date d'expiration de l'essai (le cas échéant)

## Passer à l'offre payante

<Note>
  Les règles de facturation et les tarifs seront publiés une fois le modèle de pricing finalisé.
</Note>

Une fois les crédits gratuits épuisés ou la période d'essai terminée, l'entreprise peut passer à l'offre payante depuis le Dashboard. Aucune migration technique n'est nécessaire — les Apps, clés API et webhooks existants restent opérationnels.
