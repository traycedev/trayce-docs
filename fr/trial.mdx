À la création de votre compte, Trayce alloue des **crédits d'essai**. Vous appelez la même API que en production (`https://api.trayce.africa/v1`) : créez une App dédiée aux tests si besoin.

## Utiliser les crédits

1. Créez une App dans le [Dashboard](https://app.trayce.africa).
2. Générez une clé API.
3. Envoyez vos premiers appels (`send` ou `collect`) : chaque opération consomme des crédits.
4. Suivez le solde restant dans le Dashboard (onglet App).

## Quand le solde est à zéro

Les opérations soumises à crédits sont bloquées. Passez à l'offre payante depuis le Dashboard. Vos Apps, clés API et webhooks restent inchangés : aucune migration technique.

## Bonnes pratiques

- Une App séparée pour les tests (ex. `Mon produit : Test`).
- Des données réalistes pour valider vos flux de bout en bout.
- Surveillez la consommation avant une démo ou un lancement.
