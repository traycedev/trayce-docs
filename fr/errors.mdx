## Format des erreurs

Toutes les erreurs suivent un format JSON cohérent :

```json
{
  "error": {
    "code": "INVALID_WORKFLOW",
    "message": "Le code workflow 'UNKNOWN' n'existe pas.",
    "details": {
      "field": "workflow_code",
      "provided": "UNKNOWN"
    }
  }
}
```

## Codes HTTP

| Code | Signification |
|---|---|
| `200` | Succès |
| `201` | Ressource créée |
| `400` | Requête invalide (paramètres manquants ou incorrects) |
| `401` | Non authentifié (clé API invalide ou absente) |
| `403` | Non autorisé (permission insuffisante) |
| `404` | Ressource introuvable |
| `409` | Conflit (état incompatible avec l'opération) |
| `422` | Entité non traitable (validation métier) |
| `429` | Trop de requêtes (rate limit atteint) |
| `500` | Erreur interne Trayce |

## Codes d'erreur métier

| Code | Description |
|---|---|
| `INVALID_WORKFLOW` | Code workflow inexistant. |
| `COLLECTION_ALREADY_COMPLETED` | La Collection est déjà finalisée. |
| `COLLECTION_CANCELLED` | La Collection a été annulée. |
| `PERSON_NOT_IN_COLLECTION` | La personne n'appartient pas à cette Collection. |
| `LINK_EXPIRED` | Le lien d'accès a expiré. |
| `LINK_REVOKED` | Le lien d'accès a été révoqué. |
| `DOCUMENT_TYPE_NOT_ALLOWED` | Ce type de document n'est pas autorisé pour ce workflow. |
| `FILE_TOO_LARGE` | Le fichier dépasse la taille maximale autorisée. |
| `UNSUPPORTED_FORMAT` | Format de fichier non supporté. |
| `RATE_LIMIT_EXCEEDED` | Limite de requêtes atteinte. |
| `INSUFFICIENT_CREDITS` | Crédits insuffisants pour cette opération. |

## Rate limits

Les limites varient selon le plan. En cas de dépassement, l'API répond `429` avec l'en-tête `Retry-After` indiquant le délai à attendre (en secondes).

En `429`, lisez `Retry-After` et réessayez avec un backoff.

## Idempotence

Pour les requêtes `POST`, vous pouvez passer un en-tête `Idempotency-Key` pour éviter les doublons en cas de retry :

```bash
curl -X POST https://api.trayce.africa/v1/collections \
  -H "Authorization: Bearer sk-..." \
  -H "Idempotency-Key: my-unique-key-123" \
  ...
```
