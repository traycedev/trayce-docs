<Note>Aperçu : l'API Trayce n'est pas encore ouverte et peut encore évoluer. Les organisations du programme pilote y ont accès en avant-première. [Demander une démo](https://trayce.africa).</Note>

Une erreur renvoie un code HTTP et un corps JSON :

```json
{
  "error": "invalid_request",
  "message": "recipient_phone must be E.164 (e.g. +221771234567)."
}
```

| HTTP | `error` | Signification |
|---|---|---|
| 400 | `invalid_request` | Un paramètre manque ou n'est pas valide. Le message précise lequel. |
| 401 | `invalid_api_key` | Clé absente, mal formée ou révoquée. |
| 403 | `missing_scope` | La clé n'a pas la permission nécessaire. |
| 403 | `org_inactive` | Votre organisation n'est pas active. |
| 403 | `trial_expired` | Votre période d'essai est terminée. |
| 404 | `not_found` | L'objet n'existe pas, ou n'appartient pas à votre organisation. |
| 409 | `conflict` | Même `external_id` ou même `Idempotency-Key` déjà utilisé. |
| 429 | `rate_limited` | Trop de requêtes. Voir les [limites](/fr/api-reference/rate-limits). |
| 5xx | `server_error` | Erreur de notre côté. Réessayez avec la même `Idempotency-Key`. |
