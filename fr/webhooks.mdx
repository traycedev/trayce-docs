<Note>Aperçu : l'API Trayce n'est pas encore ouverte et peut encore évoluer. Les organisations du programme pilote y ont accès en avant-première. [Demander une démo](https://trayce.africa).</Note>

Plutôt que d'interroger l'API, recevez les événements sur votre serveur : une pièce reçue, un document accepté, une vérification terminée. Voir la [liste des événements](/fr/api-reference/webhooks/events).

## Format

```json
{
  "id": "evt_6a1f…",
  "type": "collect.submitted",
  "created_at": "2026-11-24T18:02:42Z",
  "data": { "id": "c41b9e02-…", "external_id": "LOC-2026-118" }
}
```

## Vérifier la signature

Chaque événement porte l'en-tête `Trayce-Signature: t=1795394562,v1=5d3c…`.

1. Assemblez `t`, un point et le corps brut de la requête : `1795394562.{"id":"evt_6a1f…",…}`.
2. Calculez le HMAC SHA-256 de ce texte avec le `secret` de votre webhook.
3. Comparez-le à `v1`, en temps constant.
4. Refusez l'événement si `t` a plus de cinq minutes.

## Répondre et réessais

Répondez `200` rapidement, puis traitez l'événement. Sans réponse `2xx`, Trayce réessaie plusieurs fois, avec des délais croissants. Un même événement peut arriver deux fois : servez-vous de `id` pour l'ignorer.
