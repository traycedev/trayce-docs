## Contact

Pour toute question technique ou commerciale, contactez l'équipe Trayce :

- **Email** : [support@trayce.sn](mailto:support@trayce.sn)
- **Dashboard** : utilisez le bouton "Aide" depuis [app.trayce.sn](https://app.trayce.sn)

## Signalement de bugs

Si vous rencontrez un comportement inattendu ou une erreur dans l'API, incluez dans votre message :

- L'ID de la requête (en-tête `X-Request-ID` dans les réponses)
- Le endpoint concerné
- Le payload envoyé (masquez les données sensibles)
- La réponse reçue
- L'heure de la requête

## Sécurité

Pour signaler une vulnérabilité de sécurité : [security@trayce.sn](mailto:security@trayce.sn)
