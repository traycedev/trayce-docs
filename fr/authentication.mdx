<Note>Aperçu : l'API Trayce n'est pas encore ouverte et peut encore évoluer. Les organisations du programme pilote y ont accès en avant-première. [Demander une démo](https://trayce.africa).</Note>

Chaque requête porte une clé API de votre organisation :

```bash
Authorization: Bearer trc_live_…
```

## Test et live

| Clé | Effet |
|---|---|
| `trc_test_…` | Les appels sont validés, rien n'est envoyé à une personne ni facturé. Pour développer et tester. |
| `trc_live_…` | Les appels agissent réellement. Refusés si votre organisation n'est pas active ou si sa période d'essai est terminée. |

## Permissions

Chaque clé reçoit seulement les permissions dont elle a besoin. Une permission d'écriture inclut la lecture correspondante.

| Permission | Pour |
|---|---|
| `send:read`, `send:write` | Send |
| `collect:read`, `collect:write` | Collect |
| `verify:read`, `verify:write` | Verify |
| `connect:read`, `connect:write` | Connect |
| `scan:read` | Scan |
| `webhooks:read`, `webhooks:write` | Webhooks |

## Bonnes pratiques

- Gardez vos clés côté serveur, jamais dans une application mobile ou une page web.
- Une clé par outil : vous pouvez en révoquer une sans toucher aux autres.
- Révoquez immédiatement une clé exposée, depuis **Clés API**.
