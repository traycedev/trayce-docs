## Apps

Une **App** est l'identité de votre intégration : clés API, permissions, webhooks.

| | |
|---|---|
| App ID | Identifiant de l'App |
| Clés API | Authentifient vos appels |
| Permissions | Ce que l'App peut faire |
| Webhooks | URL de livraison des événements |

Vous pouvez avoir plusieurs Apps (ex. une par produit ou par environnement interne).

## Clés API

Générez-les depuis le Dashboard → paramètres de l'App.

<Warning>
  La clé complète n'est affichée **qu'à la création**. Stockez-la dans un gestionnaire de secrets. En cas de perte : nouvelle clé + révocation de l'ancienne.
</Warning>

```bash
curl https://api.trayce.africa/v1/collections \
  -H "Authorization: Bearer <votre_clé_api>" \
  -H "Content-Type: application/json"
```

### Rotation

- Révoquez une clé compromise sans délai.
- Plusieurs clés par App pour une rotation sans coupure.
- Une clé révoquée est invalidée immédiatement.

## Permissions

| Permission | Usage |
|---|---|
| `documents:write` | Envoyer des documents |
| `documents:read` | Lire documents et statuts |
| `collections:write` | Créer / modifier des Collections |
| `collections:read` | Lire Collections et résultats |
| `applications:read` | Lire les ressources App |
| `webhooks:manage` | Gérer les webhooks |

N'accordez que ce dont l'intégration a besoin.

## API Apps

```

GET    /apps
```
