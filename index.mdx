Trayce is a secure document management and identity verification platform built for businesses that need to verify who they're working with and exchange sensitive documents safely. Whether you're running KYC checks on new customers, validating business credentials, confirming academic qualifications, or verifying civil status documents, Trayce gives you a single REST API to handle it all — backed by a mobile Vault app that puts individuals in control of their own identity documents.

This documentation covers everything you need to integrate Trayce into your product: authentication, endpoint references, webhook setup, and step-by-step guides for every verification type.

## How It Works

<Steps>
  <Step title="Create a Trayce Business Account">
    Sign up at [app.trayce.io](https://app.trayce.io) to create your Business Account. Once your account is approved, you'll have access to the Business Portal where you can manage verification requests, review results, and configure your integration settings.
  </Step>
  <Step title="Generate an API Key">
    In the Business Portal, navigate to **Settings → API Keys** and generate a new key. Use a `sk_test_` prefixed key while building and testing your integration — switch to a `sk_live_` key only when you're ready to go to production.
  </Step>
  <Step title="Call a Verification Endpoint">
    Make authenticated REST API calls to request verifications. Send the type of verification you need (KYC, KYB, diploma, or civil status), along with the subject's details and any required documents. Trayce routes the request securely to the individual's Vault app if document consent is required.
  </Step>
  <Step title="Receive Results via Webhook">
    Verification results are delivered asynchronously to your configured webhook endpoint. Register a URL in **Settings → Webhooks** and Trayce will POST a signed event payload as soon as a verification completes, is flagged for review, or fails.
  </Step>
</Steps>
